Soal 3 Mengambil Data dari Database
Mengambil seluruh data users tanpa field password
db.users.find({}, { password: 0 })


Mengambil data items dengan harga di atas 1 juta
db.items.find({ price: { $gt: 1000000 } })


Mengambil data items yang namanya mirip dengan “uniklo”
db.items.find({ name: { $regex: /uniklo/i } })

db.items.find({ name: { $regex: /watch/i } })
